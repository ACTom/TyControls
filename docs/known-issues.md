# 已知问题

> English: [known-issues.en.md](known-issues.en.md)

按平台列出当前版本的已知问题。未列出的平台功能完整。遇到此外的问题欢迎提 issue。

## GTK3(仅 Wayland 会话)

GTK3 在 X11 会话下功能完整。以下问题只出现在 **Wayland** 会话,根源在 Wayland 窗口模型与上游 LCL-GTK3,库层无法绕过:

- **模态对话框不能拖动。** LCL 把无边框模态窗体创建为 Wayland 的 `xdg_popup`,这类窗口没有移动请求。
- **菜单点空白处不关闭。** 点能获得焦点的控件(按钮、输入框等)或按 `Esc` 可以关闭;下拉框不受影响,点任意处都能关。
- **弹窗是方角。** Wayland 没有 XShape,下拉、菜单、气泡等弹窗切不了圆角遮罩。
- **半透明效果透出桌面。** 禁用态变灰、`Transparent` 的标签等半透明像素会透出桌面,而不是对着窗体背景变淡。

**建议**:GTK3 下使用 X11 会话,或改用 Qt5 / Qt6。

## GTK3(用 Lazarus 4.99 以前的版本编译)

**输入法一次上屏的一长串会被截断。** 用输入法一次提交一整个词组时，控件只收到开头一两个字。LCL-GTK3 把每次提交塞进一个最多 7 个字节的字符参数;只有 Lazarus 开发主线(4.99)的 GTK3 另外留着完整的那一段，库层从那里取回;在此之前的正式版没有留，库层拿不到。X11 和 Wayland 都一样。

**建议**:GTK3 下要用中文等输入法，就用 Lazarus 4.99 及以后的版本编译，或改用 GTK2 / Qt5 / Qt6。

## GTK2 / GTK3(跟随系统外观)

`Controller.Follow := tfFollowSystem` 在 GTK 下读不到桌面的明暗与强调色:主题保持当前明暗,`system` 主题的强调色用内置的中性蓝。X11 和 Wayland 都一样。

原因在 LCL:GTK2 确实读真实的 GTK 样式,但只在 widgetset 构造时读一次,之后再不刷新;GTK3 有几项系统颜色是直接写死的,widgetset 自己都会打印警告。读到一个过期或写死的值,比承认读不到更糟,所以库层选择不读。

**建议**:需要跟随系统外观就用 Qt5 / Qt6——那里读的是 Qt 实时的调色板,桌面换配色方案能跟上。

## macOS(工程直接编译库源码时)

把 `source/` 目录直接加进工程的搜索路径、调试信息又选了 DWARF3 时,macOS 上编不过,报 `tyControls.CocoaWS.pas ... Internal error 200609171`。这是 FPC 3.2 的缺陷:它的 DWARF3 写入器不支持 Objective-C 类。通过包使用不受影响。

**建议**:通过 `tycontrols` 包使用;或者把工程的调试信息改成 DWARF2 或「自动」。

## Windows(多块显示器、缩放比例不同)

窗体拖到另一块缩放比例不同的屏幕上时,会按新屏幕的 DPI 重新排版。下拉列表、菜单、提示气泡这类弹出窗口不跟着换:它们按所属窗体的 DPI 绘制,弹到另一块屏幕上时会偏大或偏小。

**建议**:会弹出窗口的控件别紧贴屏幕边缘,让弹窗和窗体落在同一块屏幕上。
