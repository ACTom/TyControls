## 这份清单为什么存在

`2026-07-19-grid-gap-audit.md:174` 有一段**括号里的斜体文字**,列了约 20 个
"medium 尾部一并纳入、不再单列的小项",写着"建议作为顺手批次塞进各自 HIGH 条目
的同一个 PR,不单独排期"。

结果:**一条都没做,而且整批从后续所有计划里消失了**。
它们在 `grid-parity.md` / `grid-remaining.md` / `grid-architecture-audit.md`
里一次都没出现过;代码里逐个 grep 全部为 0。

对照之下,SKIP 的 12 类**每一类都附了理由**。这批一条理由都没有 ——
这不是"决定不做",是**丢了**。

**同一个失效形态出现过三次**:
1. P4 内嵌筛选行 —— 在清单里、排在 P5/P6/P7 前面,却被跳过,无说明(已补做)
2. 这一批 20 项 —— 只活在一段括号文字里,从未进入任何勾选清单
3. 若干"从句子里消失"的子项(见下 T21-T26)—— 条目被复述时少了半句

**根因**:验收时问的是"计划里还有没有未勾选项",而这三次的失效形态都是
**条目根本不在清单里**。所以才有了这份文件 —— 把它们变成能被勾的行。

**判据(以后照做)**:凡是写在括号、脚注、正文段落里的待办,
必须誊成带 `- [ ]` 的行。不能被勾的东西不会被做。

## A 组 · 数据进出(5 项)

### T1 流式读写 `SaveToStream` / `LoadFromStream`
- [ ] 与现有 CSV 文本互通:内部走 `SaveToCSVText` / `LoadFromCSVText`,
      只多一层流封装,**不新造第二套序列化**。
- [ ] 编码显式声明(UTF-8 无 BOM),别让宿主猜。
- **守卫**:存到 `TMemoryStream` 再读回来,逐格断言;空表、单格、含换行的字段各一例。

### T2 限定区域导出
- [ ] `SaveToCSVText` / `SaveToHTMLText` 接受一个可选的行列范围(缺省 = 全表)。
- [ ] 范围与**选区**打通:导出选中区域是最常见的诉求。
- **守卫**:导出一个 2x2 区域,断言行数列数与内容;范围越界时钳到表内而不是崩。

### T3 追加式 CSV 导入 + `MaxRows` / `IgnoreRows`
- [ ] 现在的 `LoadFromCSVText` 是**替换式**(先 ClearCells)。补一个追加模式。
- [ ] `MaxRows` 限制读多少行,`IgnoreRows` 跳过前几行(跳过表头之外的说明行)。
- **守卫**:追加不清空既有数据;`MaxRows=3` 时正好 3 行;`IgnoreRows` 跳过的行不进表。

### T4 JSON 导出
- [ ] 每行一个对象,键取列标题;列标题重复或为空时退回 `col0/col1`。
- [ ] **只做导出不做导入**:导入要面对任意 JSON 结构,那是"文件格式库范畴"
      (与 SKIP 掉 XLS 同一条理由)。这一条要在实现时写进注释。
- **守卫**:含引号/换行/反斜杠的格子要正确转义;空表导出 `[]`。

### T5 分区域清空 `ClearRows` / `ClearCols`
- [ ] 现在只有无参的 `ClearCells`(整表)。
- [ ] 走 `SetCells` 收口点 → 自动可撤销;整批算**一条**撤销记录。
- **守卫**:清掉的范围空了、范围外没动;一次 Ctrl+Z 全回来。

## B 组 · 编辑与否决钩子(5 项)

### T7 `OnEditChange` 逐击键回调

- [ ] `OnCanInsertRow` / `OnCanDeleteRow`,置 False 即否决。
- [ ] **这是原始 gap 清单里的正式条目 M25** —— 依赖图(gap-audit:236)引用了它,
      而编号清单只到 M24,它被降级进尾批然后蒸发。
- **守卫**:否决后行数不变、数据不动、撤销栈里不留记录。

### T9 键盘扩展事件 `OnReturn` / `OnCtrlReturn`

- **守卫**:编辑态按回车走提交,非编辑态走事件;两者不互相吃掉。

### T10 `OnScrollHint` 滚动提示

- **守卫**:拖动中回调被调用且行号正确;不拖不调。
