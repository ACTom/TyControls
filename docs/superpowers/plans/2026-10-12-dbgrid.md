## 设计

**D1 选项**：发布 `Options: TDBGridOptions`（LCL `DBGrids` 单元的类型，`.lfm` 里 `Options = [dgTitles, dgIndicator, …]` 与 LCL 窗体同名同义，移植不改），默认值同 LCL；Custom 类把它映射到底层表格的选项（标题行 = 表头可见、指示列 = `ShowIndicator`、行列线、可编辑、整行选择、Tab、多选……）。底层表格自己的选项属性在 DB 类里不发布。`OptionsExtra: TDBGridExtraOptions`（`dgeAutoColumns`、`dgeCheckboxColumn`），默认同 LCL。不支持的 LCL 选项（`dgHeaderPushedLook`、`dgDblClickAutoSize` 等表格本身没有的）照收、文档写明无效果。

**D2 列**：`Columns: TTyDBGridColumns`，项 `TTyDBGridColumn = class(TTyGridColumn)` 加 `FieldName`、`DisplayFormat`、只读的 `Field`；`Title` 用继承的标题文字。没有设计期列且 `dgeAutoColumns` 时按字段自动建列（字段可见性、`DisplayLabel`、`DisplayWidth` 换算宽度、`Alignment`、只读），自动列不写进 `.lfm`。布尔字段默认勾选框（`dgeCheckboxColumn`），查找字段默认下拉列表（列表来自 `LookupDataSet`），备注字段默认显示 `(Memo)`、`dgDisplayMemoText` 时显示内容。

**D3 数据窗口**：数据连接子类（照 V10 的回调表）；`BufferCount` 随可见行数变（尺寸变化、字体 / 主题行高变化时更新）；画行时设 `ActiveRecord` 并在 `finally` 里还原；单元格文本 `Field.DisplayText`（`DisplayFormat` 只在用户设了时推给字段，照 LCL）。

**D4 滚动**：整行滚动；滚轮、方向键、翻页、滚动条都变成 `MoveBy`；滚动条：连续数据集按 `RecNo`，不连续的三段式（照 LCL）；拖滑块：连续时 `RecNo :=`，否则按方向 `MoveBy`。

**D5 编辑**：编辑器初值 `Field.Text`（备注显示时 `AsString`），掩码 `Field.EditMask`（`OnFieldEditMask` 可改）；键入或改值时若未在编辑则 `DataLink.Edit`（失败按只读处理，键被吞）；写回在离开单元格 / 行、或数据集 `Post` 时经 `UpdateData` 写 `Field.Text`；Esc 编辑中撤销这一格、不在编辑器时 `DataSet.Cancel`；Down 过最后一行在可改且未禁止插入时 `Append`，未修改的插入行在上移 / 离开 / 失焦（`dgCancelOnExit`）时取消；Insert 键插入；Ctrl+Del 删除（`dgConfirmDelete` 时用 `TyMessageDlg`，经 protected virtual 以便测试替换）；只读的层级：表格 `ReadOnly`、`dgEditing`、数据源、字段 `CanModify`、列 `ReadOnly`、计算 / 自增 / 查找字段。

**D6 指示列**：当前记录画字形——浏览三角、编辑竖线、插入竖线（插入色）、多选时的点，经主题字形令牌（`--glyph-dbgrid-browse` 等，照 Navigator 的做法用画家线条画默认形状），颜色取指示列样式的文字色；RTL 时镜像。

**D7 多选与书签**：`dgMultiselect` 时 `SelectedRows: TTyBookmarkList`（自己写：`Count`、`Items`、`CurrentRowSelected`、`Clear`、`Delete`、`IndexOf`、`Refresh`）；Ctrl+点击切换、Shift+上下扩展、普通点击清空后选当前；`dgPersistentMultiSelect`。

**D8 排序与筛选**：表格自带的客户端排序 / 筛选 / 分组在 DB 表格里关掉（它们按客户端存储工作，与数据集冲突）；标题点击触发 `OnTitleClick(Column)`，由应用对数据集排序（文档给 `TBufDataset.IndexFieldNames` 的例子）。

**D9 事件**（发布，照 LCL 名字与签名）：`OnCellClick`、`OnColEnter` / `OnColExit`、`OnColumnMoved`、`OnColumnSized`、`OnDrawColumnCell`、`OnDrawColumnTitle`、`OnFieldEditMask`、`OnGetCellHint`、`OnPrepareCanvas`（映射到本库的单元格样式钩子：传入 `TTyStyleSet` 可改，签名不同于 LCL 的 Canvas 版——文档写明）、`OnSelectEditor`、`OnTitleClick`、`OnUserCheckboxState`、`OnEditButtonClick`；外加底层表格已有、对 DB 有意义的（`OnGetCellStyle` 等）。

**D10 汇总**：表尾汇总在 DB 表格里不自动遍历数据集（可能是百万行）；`OnColumnCalc` 照常可用，文档给「在 `AfterPost` / `AfterOpen` 时用 `DisableControls` + 书签遍历算总和」的例子。

**D11 需主控确认**（不回复按建议）：① 发布 LCL 的 `TDBGridOptions` 类型而不是本库表格的选项类型（移植友好）；② 整行滚动（放弃像素平滑），与 LCL 一致；③ 客户端排序筛选关闭、交给 `OnTitleClick`；④ `OnPrepareCanvas` 改成样式集版本；⑤ 汇总不自动遍历数据集。

### Task 3：滚动与导航
- **主控决定（2026-10-12）**：DB 表格翻页照 LCL `TDBGrid`——PgUp / PgDn 是 `DataLink.MoveBy(±VisibleRowCount)`，不照 `TTyStringGrid` 的 `PageRowStep`（留一行重叠，main 上的 #57）。理由：每个控件跟它自己的 LCL 对应物走，`TDBGrid` 翻页不留重叠行。
- 测试：方向键、PgUp / PgDn、Home / End（列）、Ctrl+Home / End（记录）、滚轮、滚动条三种操作都只经 `MoveBy` / `First` / `Last` / `RecNo`；滚动条范围与位置（连续 / 不连续两种夹具）；点击别的行 = `MoveBy(行差)`。变异：滚轮直接改 `TopRow` → 红。
- **实现时的落点（2026-10-12）**：
  - 行的移动收在 `MoveCursor` 一处：行变了就 `DataLink.MoveBy(行差)`，列再交给底层。于是方向键、Enter、Tab 折行、点击别的行、代码里 `Row :=` 全都经数据连接（Task 2 记下的“表格里动了数据集不动”就是这里补的）；DB 表格自己的 `KeyDown` 只接 Up / Down（追加、撤销新行，Task 4）、PgUp / PgDn、Ctrl+Home / End（及 Task 4 的 Esc、Insert、Ctrl+Del），这些键照 LCL 先发 `OnKeyDown`。
  - 纵向滚动条不动 Grid.pas：`ContentHeightPx` 只在 `UpdateScrollBars` 测量期间改答“记录要不要条”，底层据此摆条、让出宽度；范围与位置由 DB 表格事后写进去（自己的守卫旗，`DoVScroll` 认得）。
  - **与 LCL 的差异**：① 条的显隐：连续数据集“记录装不下窗口”才显示，不连续的“窗口满了”才显示（LCL 只要多于 1 条就显示）；② `Filtered` 在范围与拖动两处都算不连续（LCL 只在 `WMVScroll` 里算）；③ 不连续数据集拖滑块到两端也只按方向 `MoveBy(±窗口行数)`（D4），不像 LCL 那样直接 `First` / `Last`；④ 滚轮按格数走（`|delta| div 120`，至少 1），LCL 是每条消息 1 条；⑤ Enter 保留本库表格的“提交并下移”（经 `MoveBy`），LCL 是打开编辑器；⑥ Tab 在窗口最后一行不折到下一条记录（底层只在 `RowCount` 内折行），LCL 会折并可能追加。
  - 底层 `TTyCustomGrid.DoMouseWheel` 不调 `OnMouseWheel` / `OnMouseWheelUp/Down`；DB 表格照 LCL 的 `TControl.DoMouseWheel` 先问这三个事件。

### Task 4：编辑、插入、删除
- 测试（真实路径：键入、F2、Enter、Esc、方向键、点击）：键入进入 `dsEdit`；离开行写回并 `Post`；Esc 两层撤销；Down 过末行 `Append`、未改的插入行上移即取消；Insert 键；Ctrl+Del 确认后删除（替换确认函数）；各层只读；勾选框点击 / 空格切换写回；查找字段下拉选值写回键字段；校验异常时停在原格不丢输入。
- **实现时的落点（2026-10-12）**：
  - 进 `dsEdit` 挂在 `CanEditCell`（底层只在开编辑器前问它）：当前记录上开编辑器——键入、F2、双击——就 `DataLink.Edit`，被拒按只读处理（键被吞）。**与 LCL 的差异**：LCL 在第一次改值时才 `Edit`，F2 只开编辑器；本库表格没有“编辑器里敲了键”的钩子，所以开编辑器即 `Edit`。没改就离开的记录由数据集自己的 `CheckBrowseMode` 撤销，结果相同。
  - 写回：离开单元格时底层经 `SetEditText` 提交，DB 表格写字段（`Text`；备注 `AsString`；布尔勾选框按勾选词汇写 `AsBoolean`，`'2'` = NULL；别的勾选列写列的 `ValueChecked` / `ValueUnchecked`；查找字段再按 `LookupDataSet` 写键字段）；只写当前记录——多行粘贴只落当前记录那一行（LCL 没有多行粘贴）。数据集 `Post`（导航条）时编辑器还开着，`UpdateData` 先把它的文本写进去。
  - 校验异常（`Field.Text :=` / `OnValidate`，或 `Post` / `BeforePost`）：异常照 LCL 交给应用，编辑器在原格重新打开、内容是用户敲的（字段拒收时由 `GetEditText` 暂答那段文本）。**需真机看一眼**：编辑器失焦提交时被拒，会在失焦过程中重新开编辑器并给它焦点。
