# TTyGauge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. This is the **first control of Phase 1** of [the controls-expansion roadmap](../specs/2026-07-05-controls-expansion-roadmap.md); it also establishes the per-control template every later control follows.

**Goal:** Ship `TTyGauge` — a themeable value gauge (linear bar / open arc / full ring) — end-to-end (control + theming + palette + docs + example + tests), rendering pixel-identical on Windows/Linux/macOS.

**Architecture:** Leaf `TTyGraphicControl` painted via `TTyPainter`; arcs via `Painter.Bitmap.Canvas2D` (BGRABitmap), linear via `FillBackground`. Two theme typeKeys, mirroring `TTyProgressBar`/`TTyProgressFill`: **`TyGauge`** (track = `background`, `border-width` = arc/bar thickness fallback, `color` = value text) and **`TyGaugeFill`** (the value fill, gradient-capable). Value animates via the eased-position kernel (`TTyAnimator` + lazy `TTimer`), **snapping headless** (no parent handle) so render/golden tests stay pixel-stable. Nothing is hard-coded — all colours come from the theme.

**Tech Stack:** FPC/Lazarus, BGRABitmap (`Canvas2D` arcs), `.tycss`, fpcunit.

**API (shipped):** `Min/Max/Value: Double`, `Style: (gsLinearH,gsLinearV,gsArc,gsRing)=gsArc`, `ShowValue: Boolean=True`, `ValueFormat: string='%.0f'`, `Thickness: Integer=12`, `StartAngle=135`, `SweepAngle=270`, `AnimationsEnabled=True`, + `Caption/Font/Align/Anchors/StyleClass/Controller`. Pure helpers `TyGaugeFraction` / `TyGaugeSweepEnd` / `TyGaugeLinearFill`.

**Files:** Create `source/tyControls.Gauge.pas` ✓, `tests/test.gauge.pas` ✓, `docs/controls/gauge.md`, `examples/gauge/`. Modify `tycontrols.lpk` ✓, `themes/{light,dark,green,showcase,system,auto}.tycss`, `source/tyControls.DefaultTheme.pas`, `source/tyControls.BuiltinThemeData.pas`, `tests/test.themes.pas` (GGRID), `designtime/tyControls.Design.pas`, `tools/genicons/genicons.lpr`, `scripts/gen-icons.ps1`, `tests/test.paletteicons.pas`, `designtime/tycontrols_icons.lrs`, `tests/tytests.lpr` ✓, `docs/controls/README.md`, `CHANGELOG.{md,en.md}`.
