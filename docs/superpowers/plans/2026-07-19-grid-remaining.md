# TTyGrid 剩余功能 实施计划

> **执行方式**:逐项 TDD、逐项变异验证、逐项提交。每项完成后跑全量 + 重建示例。

**目标**:把 `2026-07-19-grid-parity.md` 里明确"未做/推迟"的条目一次做完,
让这个控件从"业务数据表格"补齐到"类电子表格"。

**顺序按"用户多快撞上"排**,不是按实现难度。

---

## P1 选区外框 + 填充柄

**为什么排第一**:用过 Excel 的人一分钟内就会去拖右下角;而且现在选区**连个边框都没有**,
只有一层底色。

- [x] 选区外框:活动选区矩形描一圈边。走主题 token `TyGridSelectionFrame`
      (base 层补进 `themes/light.tycss`,重跑两个生成器)。
- [x] 填充柄:选区右下角一个小方块。命中与绘制**同一个 FillHandleRect**。
- [x] 拖填充柄 → 把源区的值铺到拖出来的范围。
      语义:单格 = 复制;多格构成等差数列 = 外推;否则按源区**循环重复**。
- [x] `OnFillCells(Sender; const ASource, ATarget: TRect; var AHandled: Boolean)`
      让宿主接管(自定义序列)。
- [x] 填充走 `BeginUpdate/EndUpdate`。
- [x] **偏离**:只做纵向填充。横向拖柄在表格里少见得多,而半成品的可供性比没有更糟。
- [x] **偏离**:等差外推只认整数。浮点等差在表格里罕见,而误判的代价是把用户的数据算错 ——
      拿不准就退回"循环重复"。
- [x] 踩到的坑:柄与选区底色同为 accent → 画了等于没画;token 里加 `color:` 作描边色。
      柄探进正文窗格 1px,而光标停在固定行时那 1px 会被滚动平移 →
      chrome 必须裁到**它所属的窗格**(与行号、横格线同一类)。

**守卫**:拖出来的内容逐格断言(复制/外推/重复三种);柄的命中矩形与绘制矩形一致;
填充期间只重画一次。

## P2 行拖动(鼠标)

**为什么**:列能用鼠标拖、行不能 —— 不对称比缺失更扎眼。用户会去拖,然后什么都不发生。

- [ ] 在**行头槽**里按下并越过阈值 = 拖行(与列头拖列对称)。
      放在行头槽而不是单元格上:单元格上是框选手势,不能抢。
- [ ] 拖动时画插入位置指示线。
- [ ] 松开走现成的 `MoveRow`(它已经会搬底色/行高/合并跨度)。
- [ ] `OnRowMove(Sender; AFrom, ATo: Integer; var AAllow: Boolean)`。
- [ ] 与行高分隔线手势的优先级:分隔线优先(边缘几像素上用户想改高度)。

**守卫**:阈值以内不触发;跨过阈值后 `MoveRow` 被调用且参数正确;
`AAllow := False` 能否决;分隔线区域不触发拖行。

## P3 撤销 / 重做

**为什么**:智能粘贴会自动扩表,删行不可逆。出错代价大。

- [ ] 命令栈:`TTyGridUndoItem` 记录**逆操作**所需的最小信息。
- [ ] 覆盖:改格值、粘贴、删除区域、插入/删除行列、行移动、合并/取消合并。
- [ ] `Undo` / `Redo` / `CanUndo` / `CanRedo` / `ClearUndo` / `UndoLimit`(默认 100)。
- [ ] Ctrl+Z / Ctrl+Y 走键盘。
- [ ] 分组:一次粘贴 = 一条撤销记录(靠 BeginUpdate 期间聚合)。

**守卫**:每种操作 undo 后**逐格**回到原状(不是只看行数);redo 再来一遍;
超过 UndoLimit 时最老的被丢弃;undo 期间不再往栈里压新记录(否则自我循环)。

## P4 内嵌筛选行 + 条件组合

**为什么**:筛选下拉已经好用了,但"金额>1000 且 地区=华东"在 UI 上仍表达不了。

- [ ] 列头下面一条**筛选行**(自己一条带,不是数据行);每列一个输入框。
- [ ] 输入即筛(防抖),支持 `>100` `<=5` `<>x` `a..b` 这类前缀语法 ——
      走现成的 `SetColumnFilterEx` / `TTyGridFilterOp`,不自造第二套。
- [ ] `ShowFilterRow: Boolean`;高度进冻结带(与列头同族)。
- [ ] 多列之间 AND(与现状一致);同列多条件用 `;` 分隔走 OR。

**守卫**:筛选行不是数据行(命中/寻址/导出都不能把它算进去);
输入 `>100` 之后可见行数正确;清空恢复。

## P5 编辑器细节(M17 / M19)

- [ ] 窄列编辑时编辑器**自动加宽**到能看清内容(不改列宽,只是编辑器浮出来)。
- [ ] 下拉宽度可配(`TTyGridColumn.DropDownWidth`,0 = 跟列宽)。
- [ ] `OnGetEditorProp(Sender; ACol, ARow; AEditor: TControl)` —— 开编辑器前
      让宿主微调(比现在"要么用内建、要么自己写 EditLink"细一档)。

## P6 多级分组

- [ ] `GroupByColumns(const ACols: array of Integer)`;分组行带层级缩进。
- [ ] 小计按层级各算各的(复用 P 之前做好的 `GroupAggregateValue`)。
- [ ] 折叠状态按"层级路径"记,而不是按单个值。

## P7 版式持久化

- [ ] `SaveLayoutToString` / `LoadLayoutFromString`:列宽/列序/可见性/排序键/
      筛选/冻结数/行高。宿主自己决定存哪(注册表/ini/数据库都行)。
- [ ] 版本号前缀,不认识的版本安全跳过而不是崩。

**守卫**:改一通再 round-trip 回来,逐项断言一致;
残缺/被截断的字符串不能崩。

---

## P8 树形单元格

**排最后**:它其实是第二种形态,不是一个小特性。

- [ ] 某一列显示层级:缩进 + 展开三角 + 父子关系由宿主给
      (`OnGetNodeLevel` / `OnGetHasChildren`),控件不持有树。
- [ ] 折叠 = 把子行从显示序里去掉(复用现成的行序间接层)。
