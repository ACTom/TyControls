# TTyMaskEdit

## 1. 概述

TTyMaskEdit 是**掩码编辑框**(日期 / 电话 / IP …),继承自 [TTyEdit](edit.md),复用它的文本引擎与 `'TyEdit'` 主题。

显示的 `Text` **始终是整条掩码** —— 字面量在自己的位置上,没填的槽画占位符 —— 所以它是**按位置可寻址**的,录入也是**就地覆写**:光标可以停在任何一个可编辑槽上,敲一个键就覆写那个槽。`Mask=''` 时退化为普通编辑。

掩码语言就是 **LCL / Delphi 的那一套**(`maskedit.pp`),不再是本控件早年那三个码;详见 [3](#3-掩码语言) 与 [7.1 迁移](#71-从三码方言迁移破坏性)。

## 3. 掩码语言

### 3.1 槽位码

左列必填、右列可选 —— **这是大小写唯一的区别**,而它决定 `IsComplete` / `ValidateEdit` 认不认这个字段填完了。

| 必填 | 可选 | 接受 |
|------|------|------|
| `0` | `9` | 数字 `0-9` |
| `L` | `l` | 字母 `A-Za-z` |
| `A` | `a` | 字母或数字 |
| `C` | `c` | 任意字符(占位符除外) |
| `H` | `h` | 十六进制位(Lazarus 扩展) |
| `B` | `b` | 二进制位 `0` / `1`(Lazarus 扩展) |

### 3.2 指令

| 写法 | 含义 |
|------|------|
| `\` | 下一个字符是**字面量**(`\0` 就是一个 `0`,`\#` 就是一个 `#`) |
| `>` | 其后的槽**强制大写**,直到 `<` 或 `<>` |
| `<` | 其后的槽**强制小写** |
| `<>` | 关掉大小写强制 |
| `!` | LCL 的 "trim leading blanks"。**这里已经无事可做** —— `MaskedValue` 本来就不含任何占位符,首尾中间都不含。放行不报错,移植过来的掩码照抄即可。 |
| `;save;blank` | 掩码尾部的三段式,见 [3.4](#34-masksaveblank-三段式) |
| 其它 | **字面量**,自动插入 |

例:`00/00/0000`(日期)、`(000) 000-0000`(电话)、`000.000.000.000`(IP)、`>LL<lll`(前两位大写)。

### 3.3 与 LCL 的两处**故意**不同

| 码 | LCL/Delphi | 本控件 | 为什么 |
|----|-----------|--------|--------|
| `#` | 可选的「数字或正负号」 | **直接抛 `ETyMaskError`** | 这是两套语言**唯一含义冲突**的码。本控件从前用 `#` 表示**必填数字**;照 LCL 读,每一条现存的 `'##/##/####'` 会**悄悄变成一条空着也算填完**的掩码 —— `IsComplete` 与 `ValidateEdit` 会对空字段点头。**校验器无声地失效**,正是掩码框存在的唯一目的所要防的那件事。所以拒掉,不改读法。必填数字写 `0`,可选数字写 `9`,字面量 `#` 写 `\#`。 |
| `:` `/` | 渲染成**本地化**的时间 / 日期分隔符 | 普通字面量 | `Text` 就是显示串,而且是 **published、会流式化**的。分隔符若跟着区域设置走,同一个 `.lfm` 在两台机器上就是两个字符串,`'12/34'` 在日期分隔符不是 `/` 的机器上会**不再符合** `'00/00'`。想要哪个分隔符就写哪个。 |

其余的码、指令与三段式**都按 LCL 的含义实现**。`[abc]` 字符集是 Lazarus 的可选扩展,LCL 默认(`EnableSets = False`)也把 `[` 当字面量,这里同样。

### 3.4 `mask;save;blank` 三段式

按 LCL 的 `SplitEditMask` 从**尾部**切:最后两个或四个字符,且 `;` 本身没有被 `\` 转义;其它位置的 `;` 是普通字面量。

- 第三段 = **占位符**,等价于写 `SpaceChar`。
- 第二段 = **是否把字面量算进值里**,即 `MaskSavesLiterals`。

```pascal
M.Mask := '00/00;1;*';   // 占位符 '*',值里带 '/'
M.Text := '12/34';
// M.MaskedValue = '12/34'

M.Mask := '00/00;0;_';   // 值里不带 '/'
M.Text := '12/34';
// M.MaskedValue = '1234'
```

> **默认值与 LCL 不同(有意):** 没写第二段的掩码,`MaskSavesLiterals` 读作 `False`,也就是本控件一贯的 `MaskedValue`(`'12/__/____'` → `'12'`)。LCL 的隐含默认是 `True`,但 LCL 那个标志管的是它的 `Text`,而本控件的 `Text` 是显示串 —— 两者不是同一个东西,没有可兼容的对象。同理,**没写第三段的掩码不会重置 `SpaceChar`**(LCL 会无条件重置成 `'_'`,那会把 `SpaceChar := #0` 在每次换掩码时悄悄撤销)。

### 3.5 唯一剩下的拒绝

**非空掩码但一个可编辑槽都没有**(`'---'`、`'()'`、`'\0\0'`、`'>!<'`)—— 抛 `ETyMaskError`。收不到输入的字段没有合理用途;要惰性字段请用 `Mask := ''`(普通编辑)或 `ReadOnly := True`。

`Mask := ''` 永远合法,含义是"没有掩码 = 普通编辑"。想先检查再赋值,用纯函数 `TyMaskRejectReason(AMask)`:返回 `''` 表示可用,否则返回拒绝原因(就是异常里那段话)。

## 4. 属性 / 方法

| 成员 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `Mask` | `string` | `''` | 掩码模板;运行期改变会清空当前内容。**流式保存的是这个名字。** 非法掩码抛 `ETyMaskError`(见 3.3 / 3.5)。 |
| `EditMask` | `string` | `''` | `Mask` 的别名(LCL / Delphi 用的名字),**同一个字段**,不参与流式化。 |
| `Text` | `TCaption` | 空骨架 | 掩码后的显示串,**含占位骨架**(见 4.1)。**赋值会过掩码**,见 5.1。 |
| `SpaceChar` | `Char` | `'_'` | 未录入槽位上画的**占位符**,同 LCL 的 `SpaceChar`(`maskedit.pp:305`)。它同时是"就地编辑"能成立的前提,见 4.1。 |
| `IsComplete` | `function: Boolean` | — | 所有**必填**槽是否填满(可选槽空着不算没填完);占位符**不算填过**。 |
| `MaskedValue` | `function: string` | — | 去掉占位符后的**有效字符**,即显示串背后的"值";字面量默认也去掉,除非掩码用 `;1;` 要求保留。`M.Text` 是 `'12/__/____'`,`M.MaskedValue` 是 `'12'`。 |
| `MaskSavesLiterals` | `Boolean`(只读) | `False` | 掩码 `;save;` 段的值,见 3.4。 |
| `ValidateEdit` | `procedure; virtual` | — | 掩码在用而必填槽没填满时抛 `ETyMaskError`;`Mask = ''` 时什么也不做。见 5.2。 |
| `ETyMaskError` | `class(Exception)` | — | 掩码不被接受、或校验不过时抛出。 |

另继承 [TTyEdit](edit.md) 的 `Alignment` / `ReadOnly` / `OnChange` 等。

### 纯函数

全部逻辑都在可单测的纯函数里:

| 函数 | 作用 |
|------|------|
| `TyMaskParse(AMask): TTyMaskSpec` | 编译掩码:每个显示位置一个 `TTyMaskCell`(字面量 / 槽,必填与否,大小写区),外加 `Blank` / `SaveLiterals` / `TrimLeft` / `Reject` |
| `TyMaskRejectReason(AMask)` | `''` = 可用;否则是拒绝原因 |
| `TyMaskSlotAccepts(ASlot, ACh [, ABlank])` | 某个**码**收不收某个字符 |
| `TyMaskApply(AMask, ARaw [, ABlank])` | **打包式**铺开:把有效字符依次塞进槽里(`Text :=` 与粘贴用的那套) |
| `TyMaskNormalize(AMask, AText, ABlank)` | **按位置**重建:**保留中间的洞**(就地编辑产生的形状) |
| `TyMaskConforms(AMask, AText [, ABlank])` | 是否恰好就是这条掩码的产物 |
| `TyMaskExtract(AMask, AText [, ABlank])` | 取回有效字符 |
| `TyMaskIsComplete(AMask, AText [, ABlank])` | 必填槽是否都满了 |
| `TyMaskNextSlot` / `TyMaskCaretSlot` | 下一个待填槽的**码** / 光标该落的下标 |
| `TyMaskCellCount` / `TyMaskIsLiteralAt` / `TyMaskNextEditable` / `TyMaskPrevEditable` | 位置查询,就地编辑靠它们导航 |

## 5. 行为

### 4.1 占位骨架(`SpaceChar`)与就地编辑

**空的掩码框显示 `__/__/____`,打了两位显示 `12/__/____`。** 占位符由 `SpaceChar` 决定,默认 `'_'`(与 LCL / Delphi 同)。

它不只是好看:**骨架让显示串变成定长、可寻址的**,于是

- **光标可以停在任何一个可编辑槽上**,敲键就**覆写那个槽** —— 改日期的月份不用先把年份删掉。
- **退格 / Delete 分家了**:退格清掉光标**前面**那个槽,Delete 清掉光标**所在**那个槽,两者都**跳过**字面量(不会把 `/` 删掉)。
- **中间可以有洞**(`'_2/34'`)。`MaskedValue` 跳过洞,`IsComplete` 因为洞而为 `False`,`Text := Text` 保留洞不会把右边的字符往左挤。
- **粘贴落在光标处**,不是从头开始。
- **选中一段再打字 / 剪切**:被选中的槽**就地清空**,显示串长度不变(基类的做法是把字符**剪掉**,那会让后面每个字符滑进另一格)。

`SpaceChar := #0` **关掉骨架**,退回从前那种短显示串 —— 此时没有可放光标的空槽,录入回到**追加式**。两个后果值得先知道:

- `Text` 是**显示串**,所以骨架在时,没动过的字段读出来是 `'__/__/____'` 而不是 `''`。值请读 `MaskedValue`;`IsComplete` 与 `TyMaskExtract` 本来就会跳过占位符。
- `TextHint` 只在 `Text` 为空时画,所以骨架把它顶掉了。这是有意的 —— 骨架说得比提示多,而且不会在第一个键落下时消失 —— 但依赖 `TextHint` 的控件要写 `SpaceChar := #0`。

### 5.1 `Text :=` / 粘贴:一套规则,只截断不补白

赋值和粘贴走**同一条判定**(所以 `Ed.Text := S` 和 Ctrl+V 同一个 `S` 不可能给出不同结果):把来的字符依次喂给下一个空槽,**合的留下、不合的丢掉**,字面量由掩码自己重建。

```pascal
D.Mask := '0000-00-00';
D.Text := '2026/07/30';   // 斜杠不是掩码要的分隔符 -> 丢掉,数字入槽 -> '2026-07-30'
D.Text := 'hello world';  // 一个都不合 -> '____-__-__'
D.Text := '123456789';    // 超出槽数的部分丢掉
```

**永不拒绝、永不抛异常** —— 这一点和 LCL 一致(`maskedit.pp:1656 ApplyMaskToText`,原注释就写着 "The text that is set, does not need to validate")。截断与补白都照做。

**已经合规的串**(本控件自己的显示串、`.lfm` 里的值、从另一个掩码框复制过来的值)**原样保留**,`Ed.Text := Ed.Text` 是恒等。

> **这条不是可有可无的优化。** `C` 收任意字符,**包括掩码自己的字面量**;若把已经合规的 `'a-b'` 再打包一遍,`-` 会被当成第二个槽的内容,变成 `'a--'`。同理,`_` 若不被排除在"内容"之外,一个带洞的串会把自己的占位符读成数据。这两道排除是 `Text := Text` 不毁数据的全部依靠。

> **注意(静态绑定):** `Text` 是属性覆盖,只拦通过 `TTyMaskEdit`(或其子类)类型引用的赋值。强转到基类 —— `TTyEdit(M).Text := X` —— 仍然会绕过掩码。别这么写。

### 5.2 校验时机:`ValidateEdit` 与失焦自动校验

- `ValidateEdit`(public virtual):掩码在用且**必填**槽没填满就抛 `ETyMaskError`。可以在 OK 按钮里主动调,也可以重写它换一种报法。
- **失焦时自动调一次**,照抄 LCL 的三道闸(`maskedit.pp:2094-2112`),每一道都有用:
  1. **先**跑 `inherited DoExit`,让 `OnExit` 处理器有机会先把值补齐或清掉;
  2. 本次焦点访问内**用户没改过**就不查(Tab 划过一个没碰过的字段不是错误);
  3. 一个失败只报一次 —— 前一个异常还没退栈时再抛一个会**中止整个程序**。

> **迁移:** 若你的表单本来就允许半截值离开掩码框,把该字段的 `Mask` 设为 `''`(普通编辑),或重写 `ValidateEdit` 改成不抛,或把该槽写成**可选**码(小写)。

## 7. 注意事项

### 7.1 从三码方言迁移(**破坏性**)

本控件从前的掩码语言只有三个码:`#` = 数字、`L` = 字母、`C` = 任意非空格,其余一律字面量。现在说的是 LCL / Delphi 的语言。逐条改:

| 旧写法 | 新写法 | 说明 |
|--------|--------|------|
| `#` | `0` | 必填数字。**不改会抛 `ETyMaskError`** —— 这是有意的,见 3.3。 |
| `L` | `L` | **不变**,两套语言含义相同。 |
| `C` | `C` | 含义**几乎**相同:LCL 的 `C` 排除的是**占位符**,不是空格,所以现在 `C` 收空格。 |
| 任何**当字面量用**的 `0 9 a A c l h H b B \ > < !` | 前面加 `\` | 这些字符现在是码。例:旧的年份掩码 `19##` → `1\900`,旧的 `!##` → `\!00`。 |
| 含 `;` 的掩码 | 照抄即可 | 三段式现在**被实现了**,不再拒绝。 |

**只有 `#` 会报错;其余是静默改变含义。** 升级时请把**每一条**掩码串过一遍上表,别只查带 `#` 的那些。`Mask` 与 `EditMask` 都可以用 `TyMaskRejectReason` 先验。

### 7.2 其它

- **换掩码清空:** 运行期设置新 `Mask` 会清空当前内容(掩码一般在使用前设定)。**流式化时例外**:`Text` 的 RTTI 槽位继承自 `TTyEdit`,写出时排在子类的 `Mask` **前面**,读回来时掩码还没生效;所以 `csLoading` 期间不清空,而是把已读进来的 `Text` 重新过一遍新掩码 —— 否则设计期填的值每次加载都会丢。
- **校验:** `Text` 赋值和粘贴都过掩码,但"过了掩码"只保证**合规**,不保证**填满**;提交处仍应用 `IsComplete` 把关。
- **多字节:** 槽位按字节判定,`C` 目前不收多字节字符(LCL 收)。掩码串本身按 ASCII 写。
- **`PasteFromClipboard` / `SelText :=`:** 键盘上的 Ctrl+V 与 Ctrl+X 由本控件自己接管,落在光标处、就地清空;但基类的 `PasteFromClipboard` / `CutToClipboard` **不是 virtual**,直接调它们时选区仍走基类的"剪切拼接",在定长骨架上会错位。要么走键盘路径,要么先自己清选区。
